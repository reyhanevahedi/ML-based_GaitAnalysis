# ML-based_GaitAnalysis
# Gait Analysis and Machine Learning-Based Classification of ALS

This project investigates the application of computational signal processing and machine learning to **human gait analysis**, using the PhysioNet Gait Dynamics in Neuro-Degenerative Disease Database. The objective is to identify gait characteristics associated with Amyotrophic Lateral Sclerosis (ALS) by analysing foot-ground interaction signals recorded through force-sensitive resistors during walking. Separate left- and right-foot recordings are processed to investigate temporal variations in locomotion and distinguish gait patterns between ALS patients and healthy control subjects.
 
The analysis combines **stride detection, temporal feature extraction, and dynamic time warping (DTW)** to characterise gait dynamics. Individual steps are identified using midpoint-crossing detection, enabling the estimation of inter-stride intervals and their temporal variability. DTW is subsequently employed to align and compare gait-signal segments independently of differences in walking speed, providing a quantitative measure of changes in gait-signal morphology over time. These complementary features are then used to construct a feature-based classification framework, with Support Vector Machine (SVM) models evaluated for distinguishing ALS patients from healthy controls. The best-performing models achieved a reported classification accuracy of 92.3% on the available dataset, although the limited number of recordings (26) was recognised as an important constraint on generalisability.
 
The project demonstrates an application of **signal-based movement analysis, temporal pattern recognition, and machine learning for the computational characterisation of human locomotion**, providing a foundation for investigating gait abnormalities and motor dysfunction through quantitative movement representations.
